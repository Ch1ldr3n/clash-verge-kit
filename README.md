# Clash Verge Kit

[简体中文](README.md) | [English](README.en.md)

Clash Verge Kit 是一个面向 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) 的本机命令行工具。它帮助你把多个子订阅分别组织成代理组，再安全地加入现有主订阅。

> 当前状态：项目尚未发布到 npm。现在请从源码运行，暂时没有可用的 `npm` 或 `npx` 一键安装命令。

当前开发工作区已支持 AI 分流：启动后选择“只配置 AI 分流”，选择目标后复用已有 `select` 组，或从目标和本机子订阅分页查找、手选节点创建出口。再次进入会恢复已保存方案，可改出口、增减节点或关闭 AI。读取已有嵌套脚本后加入分流会保留嵌套关系。

新方案使用 MetaCubeX `category-ai-!cn` 综合规则，由 Mihomo 下载更新；其范围包含部分共用服务与素材网站。旧方案保留原规则源，不静默换源。复用原组时，其直连等策略不变；手选组在成功更新后全部候选消失时阻断，更新失败允许保留最后有效候选。写入后仍需重新激活并检查规则下载和连接记录。

手选功能要求可核实的 **Mihomo 1.19.29 或更新稳定版**。本机节点列表是检查快照，不能证明连通性；无法读取的 provider 不当作零节点。规则首次下载失败时，内核可能继续走机场原路由，写入成功不能代替生效检查。[验收记录](docs/research/2026-09-08-routing-v1-acceptance.md)列出实测及边界。

## 它解决什么问题

如果你在 Clash Verge Rev 中使用多个订阅，手工编写嵌套脚本通常需要自己处理订阅来源、代理组名称、重复项和脚本写入位置。Clash Verge Kit 把这些步骤整理成一个终端向导，并在真正写入前让你检查结果。

目前支持：

- 读取 Clash Verge Rev 已导入的本机订阅；
- 选择目标主订阅和主代理组；
- 添加本机子订阅，或手工输入子订阅的公网 HTTPS 地址；
- 为每个子订阅生成独立代理组；
- 独立配置 AI 分流，或与嵌套共存；
- 按来源手选静态节点和可读取的动态 provider 节点，保持机场原节点名称；
- 回读、编辑和关闭通过完整脚本校验的已保存分流；
- 查看配置摘要和隐藏敏感来源的脚本预览；
- 将完整脚本复制到剪贴板；
- 经你确认后，安全写入目标订阅已经绑定的脚本文件。

## 现在怎么使用

使用前需要：

- Node.js 22.12.0 或更高版本；
- 已安装 Clash Verge Rev；
- 目标主订阅已经导入 Clash Verge Rev。

在终端运行：

```powershell
git clone https://github.com/Ch1ldr3n/clash-verge-kit.git
cd clash-verge-kit
npm.cmd ci
npm.cmd run cli
```

Windows 用户安装依赖后，也可以双击仓库根目录的 `clash-verge-kit.cmd`。第一次运行会构建 CLI，以后会直接启动已有构建产物。

## 使用流程

1. 选择界面语言、功能和目标主订阅。
2. 只配置 AI 时，恢复已保存方案或新建；选择已有组，或手选节点。嵌套入口另需选择主代理组和子订阅。
3. 手选节点可翻页、按名称筛选、从本机子订阅添加；已有选择可以取消。动态来源尚无可读缓存时，先在 Verge 刷新再重试。
4. 检查 AI 出口、候选与缺失来源，确认要交付的当前草稿。
5. 选择复制脚本，或确认后写入目标脚本文件。
6. 回到 Clash Verge Rev，重新激活目标订阅并检查结果。

写入成功只代表脚本文件已经更新。Clash Verge Kit 不会自动重启或控制 Clash Verge Rev，也不会把“文件已写入”当成“配置已经生效”。

V3 写入前会在原脚本旁保留 `.kit-backup-<摘要>` 副本；恢复副本后也要重新激活。完整识别的 V1/V2 已有组方案可迁移；旧 V1 克隆组、未知或被改动脚本保持只读。复制尚未安装的脚本不能自动回读。来源地址或支持能力变化后须重新检查、确认，不沿用陈旧检查结果。

## 安全与隐私

- 未保存草稿只在当前 CLI 进程中；保存后必要来源信息位于目标脚本及本机备份，均应按敏感文件保管；
- 终端不会输出完整脚本，预览会隐藏订阅来源；
- 工具不会修改 `profiles.yaml`；
- 未经确认不会联网检查订阅或写入文件；
- 未知自定义脚本、异常路径、符号链接、Windows Junction 和并发变化会被拒绝；
- 请勿在仓库、Issue、截图或日志中公开真实订阅 URL、token、`profiles.yaml`、YAML 原文或完整生成脚本。

完整边界见 [安全说明](SECURITY.md)。
