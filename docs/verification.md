# 验证与验收说明

本文说明 CLI-only 产品的自动化覆盖范围和真实环境人工确认边界。验证过程不得使用或记录真实订阅 URL、token、`profiles.yaml`、YAML 原文或完整生成脚本。

## 完整自动化验收

```powershell
npm.cmd test
npm.cmd run build:cli
npm.cmd run verify:privacy
npm.cmd run verify:package
```

也可以运行：

```powershell
npm.cmd run check
```

- `npm.cmd test`：只运行 Node/Vitest 的 CLI 工作流、共用生成器、本机发现、配置仓库、远程读取、安全写入、脚本格式和会话单元测试。
- `npm.cmd run build:cli`：执行 TypeScript 检查，并生成 `dist/cli/cli.mjs`。
- `npm.cmd run verify:privacy`：检查 CLI 构建无 source map 和禁止测试标记，且包配置、依赖、npm scripts 与 `.cmd` 没有残留 Web 入口。
- `npm.cmd run verify:package`：执行 npm pack dry-run；包只应含 `LICENSE`、`README.md`、`dist/cli/cli.mjs` 和 `package.json`。

当前验收不运行浏览器、Playwright、本机 HTTP 服务或 Web E2E。任何一项退出码非零都不能宣称完整验收通过。

## 发行前 `.tgz` 冒烟

```powershell
npm.cmd run check:release
```

这会先执行完整自动化验收，再在独立临时目录中生成 `.tgz`、使用隔离 npm 缓存和全局安装前缀安装该包，并通过安装后的 `clash-verge-kit` 命令输入 `0` 验证语言菜单可启动。临时文件会在结束时删除；它不发布 npm 包、不改变 GitHub 仓库可见性，也不访问真实 Clash Verge Rev 配置或订阅。安装阶段可访问 npm registry 以解析声明的运行时依赖。

## CLI 人工冒烟

```powershell
npm.cmd run cli
```

1. 首次缺少 `dist/cli/cli.mjs` 时确认 CMD 只构建一次；已有产物再次双击时应直接进入语言菜单，不再出现 Vite 模块构建日志。
2. 确认启动后只有终端交互，没有浏览器、localhost 或额外窗口。
3. 在首次语言菜单输入 `0` 应直接退出，不得反复显示语言菜单；选择语言后，目标主订阅菜单的 `0` 应显示“退出”并直接结束 CLI，不得原地重显；目标选定后的菜单和返回提示只使用当前语言，可返回步骤统一使用 `0`，且只回到紧邻上一步。
4. 当前订阅应只在统一目标列表中出现一次并置顶标记为推荐；仍可改选其他本机目标，但不得出现“手工输入目标主订阅”。未发现本机配置时只允许指定配置位置，并提示先在 Clash Verge Rev 导入目标主订阅。
5. 唯一检测到的 `select` 主代理组应自动使用，不再出现主代理组菜单；多个结果只列出真实检测到的组并标明总数，每页最多显示 10 个，超过一页时可前后翻页或输入关键词筛选。不得出现“高级选项”、运行时猜测或手工输入主代理组。超过 256 个时应明确提示只保留前 256 个；未检测到时应返回目标主订阅列表。组名前置图标与文字之间应有显示间距，选中后仍使用原始组名。
6. 每个数字选择菜单前应有空行和带当前提示的文本分隔线；关闭颜色或使用不支持 ANSI 的终端时，菜单层级仍应清楚。
7. 选择本机子订阅后应直接生成同名子组，不再询问一次默认子组名称；重复选择同一来源应被拒绝；生成后的“请选择下一步”应直接列出检查方向、追加、改名、详情、遮罩脚本和重新配置，不得再出现“更多操作”入口或第二层菜单。自动化边界测试还应确认第 64 个可加入，第 65 次追加只显示上限提示且不再打开子订阅选择。
8. 手工输入子订阅时使用明显虚构的 `https://example.test/...` 并拒绝联网检查；确认 CLI 不发起请求且允许补充子订阅名称。联网检查只访问输入的子订阅地址，不进行互联网搜索。
9. 检查生成后默认只显示一行摘要和必要警告，不自动打印遮罩脚本。
10. 在生成后的操作菜单中主动查看遮罩脚本，确认来源已遮罩；验证剪贴板导出时，确认终端没有回显完整脚本。
11. “检查方向并继续”只显示一次完整方向清单，并在同一页提供写入、复制和重新配置；不得再出现第二层“方向正确”菜单。
12. 需要验证写入时，只选择确认属于官方默认脚本或 Kit 已管理脚本的测试订阅。写入或复制成功后应进入完成页，只显示“重新配置”和 `0. 完成并退出`，不能再次写入或复制。
13. 当前目标写入完成页应明确“无需更新主订阅”，同时要求回到 Clash Verge Rev 重新激活当前订阅；选择其他目标时应提示激活该目标订阅。
14. 重新激活后检查嵌套子组正常出现且没有重复；原有节点和新增子组顺序不因本次菜单优化改变，Kit 不自动切换主代理组当前选中项；自动化不把“文件已写入”当作“运行配置已应用”。

真实终端、剪贴板、本机 Clash Verge Rev 目录和重新激活行为仍需要人工冒烟。

## npm 启动故障的判断

先在普通 PowerShell 中运行：

```powershell
node --version
npm.cmd --version
```

如果普通 PowerShell 正常、但受限自动化环境报错指向用户 `AppData\Roaming\npm`，先按执行环境权限问题处理，不要据此删除或重装全局 npm。可以直接调用系统 Node 安装中实际存在的 `npm-cli.js`。只有普通 PowerShell也能稳定复现失败时，才进入 Node/npm 安装修复。
