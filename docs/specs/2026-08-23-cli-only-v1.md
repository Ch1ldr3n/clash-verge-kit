# Spec: Clash Verge Kit CLI-only V1

状态：已批准
批准日期：2026-08-23
适用范围：Clash Verge Kit 当前产品与实现

## Objective

Clash Verge Kit 是供单个用户在本机终端中使用的 Clash Verge Rev 工具箱；当前正式能力是嵌套脚本生成与安全写入。成功意味着用户只通过 CLI 完成本机配置发现、目标与子订阅选择、脚本生成、遮罩检查、剪贴板导出或安全脚本写入；运行过程不需要浏览器、localhost 服务或第二套生成器。

## Product Entry

- 唯一正式产品入口是 Node.js CLI。
- 源码工作区使用 `npm run cli`；构建产物使用 `node dist/cli/cli.mjs`。
- `clash-verge-kit.cmd` 只运行同一个 CLI 构建产物：产物缺失时执行一次 `npm.cmd run build:cli`，已有产物时直接用 Node 启动；不得打开浏览器、启动后台服务或维护独立业务逻辑。
- npm 包通过 `bin.clash-verge-kit` 公开分发；首次发布后，普通用户使用 `npx clash-verge-kit`，无需克隆源码。

## Tech Stack

- Node.js 22.12.0 或更高版本
- TypeScript 7.0.2
- YAML 2.9.0
- Vite 8.2.0，仅用于打包 Node CLI
- Vitest 4.1.10

React、React DOM、Playwright、浏览器 Vite 插件和 localhost 服务不属于当前技术栈。

## Functional Requirements

### 1. CLI 交互

- 启动时选择中文或 English；后续提示和诊断使用所选语言。
- 选定语言后，菜单、返回提示和输入校验不得继续混排另一种语言。
- 首次语言菜单和目标主订阅菜单使用数字 `0` 完成退出；目标选定后的其他可返回菜单、输入和确认步骤统一使用数字 `0` 返回，且只到紧邻的上一步，不得越级回到语言选择或丢弃仍可复用的选择。
- 每个数字选择菜单前必须输出一个空行和一条包含当前提示的文本分隔线，使相邻结果与下一组编号在无颜色终端中仍能明确分层；颜色不得成为识别层级或选项状态的必要条件。
- `Ctrl+C` 按用户取消处理，不导出、不写文件并正常退出。
- 意外错误只显示不含敏感值的安全错误信息。

### 2. 本机配置识别

- 按 Clash Verge Rev 官方系统数据目录规则检查有限候选。
- Windows 额外从运行进程和安装记录识别其他盘的便携配置。
- 自动识别失败时，允许用户指定安装目录、配置目录或 `profiles.yaml`；不递归扫描硬盘。
- 初始列表只显示名称、状态、是否为当前订阅和进程内不透明 ID，不显示订阅来源。
- 当前订阅在统一目标列表中置顶并标记为推荐；不得先显示推荐页、再重复显示同一订阅列表。用户仍可选择其他本机目标主订阅。

### 3. 目标与子订阅

- 用户选择目标主订阅、主代理组和一个或多个子订阅。
- 每个子订阅使用该 provider 的全部节点生成一个独立子组，不选择其原配置内部代理组。
- 阻止目标来源自嵌套和重复加入同一子订阅。
- 同一嵌套配置最多支持 64 个子订阅；达到上限后 CLI 必须明确提示并留在生成后操作菜单，不得打开第 65 次子订阅选择。生成器必须把超限输入返回为无效诊断，不得抛出内部元数据异常。
- 目标主订阅必须来自 Clash Verge Rev 本机发现；不得使用手工 URL 代替本机订阅身份。自动发现失败时允许指定安装目录、配置目录或 `profiles.yaml`；仍未找到时提示用户先在 Clash Verge Rev 导入目标主订阅。
- 唯一检测到的 `select` 主代理组必须自动使用；检测到多个时，只显示这些真实代理组并保持原配置顺序，每页最多显示 10 个，超过一页时必须支持上一页、下一页和关键词筛选。安全检查最多保留前 256 个，超过时必须提示列表已截断。不得把 `MATCH`/`FINAL` 兜底目标推断为主代理组，也不得提供运行时猜测或手工输入主代理组的入口。组名前置图标可在菜单显示层补间距，但生成时必须保留原始组名。未检测到主代理组时必须返回目标主订阅选择。
- 选择子订阅后直接使用订阅名称作为默认子组名称，不在初始流程重复询问；显式改名保留在生成后的操作菜单。

### 4. 订阅检查

- 本机缓存读取不发起远程请求。
- 每个手工子订阅 URL 只有在用户逐项确认后才允许联网检查。
- 联网检查直接访问用户输入的公网 HTTPS 地址，不调用搜索引擎。
- 远程读取执行公网 HTTPS、DNS、跳转、超时、响应大小和格式限制。
- 检查只产生名称、格式、可选代理组、节点数量和警告组成的受限摘要。
- 本机、远程和手工名称进入终端前必须拒绝控制字符和双向文本控制字符；危险名称不得进入菜单或确认信息。
- 手工子订阅检查失败或用户拒绝检查时，仍可在补齐生成所需信息后继续。

### 5. 生成与预览

- CLI 必须调用现有 `GeneratorSpec` 和 TypeScript 生成器，不重新实现脚本生成规则。
- 生成后默认只显示目标、主代理组、子订阅数量组成的一行摘要，以及必要的警告或错误。
- 生成后的“请选择下一步”必须使用单层菜单，按顺序直接提供“检查方向并继续（推荐）”“追加子订阅”“修改最后一个子组名称”“查看配置详情”“查看遮罩脚本”和“重新开始配置”；不得再显示“更多操作”入口或第二层操作菜单。
- 遮罩脚本只有在用户明确选择查看时才显示；完整脚本始终不得回显到终端。
- 追加子订阅或修改最后一个子组名称后自动生成最新结果。
- 无效或过期结果不能导出或写入。

### 6. 导出与安全写入

- 单次交付复核明确列出目标主订阅，并逐项显示“子订阅名称 → 子组名称”；用户在该页直接选择写入、复制或重新配置，不再进入第二个方向确认菜单。
- 剪贴板导出不创建临时文件，不在终端回显完整脚本。
- 剪贴板导出和安全写入必须保留生成器输出的可读换行、缩进与固定注释，不得把多个语句压到同一行。
- 安全写入只定位目标订阅已经绑定、位于已识别配置根目录内的独立 `s*.js`。
- 只覆盖空白、官方默认 no-op 或完整性校验通过的 Kit 已管理脚本。
- 异常路径、符号链接、Windows Junction、未知自定义脚本、无绑定、无效脚本或并发变化必须拒绝。
- 不修改 `profiles.yaml`，不自动重启、刷新或控制 Clash Verge Rev；写入后明确提示无需更新主订阅，但必须重新激活当前订阅，或激活所选的其他目标订阅。
- 不调用 Clash Verge Rev External Controller 或其他客户端接口改变主代理组的当前选中项；不重排主代理组中的原有节点或新增子组来模拟自动选择。
- 成功写入或复制后进入完成状态，只允许重新配置或完成退出；失败或安全拒绝不得进入完成状态。

### 7. 数据生命周期

- 语言、订阅来源、检查摘要、生成规格和脚本只存在于当前 CLI 进程内存。
- URL 在输入时可见，之后不在摘要、诊断或日志中再次显示。
- 完整脚本只在用户确认后进入剪贴板或目标脚本文件。
- 进程退出后不保存会话或敏感历史。

## Shared Core Contract

- `src/generator.ts` 继续拥有脚本生成与安全不变量。
- `src/integrity.ts` 和 `src/script-import.ts` 继续拥有管理元数据与完整性合同；安全写入依赖它们识别 Kit 已管理脚本。
- `src/workspace-session.ts` 只保存草稿与同步生成的最新结果，阻止旧结果导出，不保留未被业务使用的修订历史。
- 本机发现、远程读取和生成器通过明确接口连接，CLI 工作流测试不得接触真实订阅或公网。
- 重复来源与 64/65 个子订阅边界必须同时覆盖 CLI 和生成器；直接调用生成器也不得绕过这些安全不变量。

## Testing Strategy

- Vitest 只运行 CLI 工作流、共用核心和 CLI 使用的本机/网络适配器单元测试。
- `npm run build:cli` 执行 TypeScript 检查并生成唯一 CLI 产物。
- 隐私检查确认没有 source map、禁止测试标记、Web 依赖、Web scripts 或浏览器启动残留。
- npm pack dry-run 检查包白名单。
- 当前验收不安装浏览器、不运行 Playwright、不启动 localhost 服务，也不做页面 E2E。
- 测试不得读取或写入真实 Clash Verge Rev 配置；文件写入使用临时目录。

## Boundaries

### Always

- CLI 是唯一正式入口，`.cmd` 只调用 CLI。
- 复用同一个 TypeScript 生成器和安全写入实现。
- 默认遮罩敏感来源；完整脚本不打印到终端。
- 远程读取与脚本写入必须取得明确确认。
- 用户可见行为变化同步更新 README、正式规格、CONTEXT 和相关 ADR。

### Ask First

- 添加或升级依赖。
- 修改 CI、npm 发布自动化或 Git 分支策略。
- 执行 npm 发布，或发布 EXE、安装程序。
- 修改脚本格式的向后兼容规则。
- 恢复 Web、服务端或其他产品入口。

### Never

- 维护第二套生成器或第二套脚本写入业务实现。
- 记录或提交真实订阅 URL、token、`profiles.yaml`、YAML 原文或完整生成脚本。
- 未经确认联网、写文件或覆盖未知自定义脚本。
- 把“文件写入成功”描述成“Clash Verge Rev 已应用”。
- 在 CLI-only V1 中加入浏览器界面、localhost 服务、账号、云端同步、遥测或第三方分析。

## Success Criteria

- [x] `npm run cli` 只启动终端流程，不打开浏览器、不监听端口。
- [x] `clash-verge-kit.cmd` 复用现有 CLI 构建；只有缺少产物时才构建一次。
- [x] 能发现当前订阅或改选其他本机订阅；找不到目标时提示指定配置位置或先在 Clash Verge Rev 导入。
- [x] 能自动使用唯一真实主代理组，或从多个检测结果中选择主代理组，再选择多个子订阅并生成最新有效结果。
- [x] 终端默认只显示简短摘要和必要警告，遮罩脚本只能按需查看。
- [x] 在单次方向复核页可复制完整脚本或安全写入已绑定脚本，成功后进入完成状态。
- [x] 复制和写入的完整脚本保持生成器原有的可读换行与缩进。
- [x] 写入不修改 `profiles.yaml`，未知脚本和异常路径被拒绝。
- [x] React 页面、localhost 服务、Web 测试、浏览器 E2E 和旧浏览器启动入口已移除。
- [x] Web 构建脚本、依赖和配置已移除。
- [x] CLI 单元测试、CLI 构建、隐私检查和打包检查全部通过。

## Out of Scope

- AI 配置、更新、复原和用户脚本导入交互
- 自动重启或立即应用 Clash Verge Rev
- 自动选择主代理组中的子组或节点
- 浏览器或桌面图形界面
- localhost 或公网服务
- 自包含 EXE 和安装程序
- 账号、持久化、云端同步和遥测
