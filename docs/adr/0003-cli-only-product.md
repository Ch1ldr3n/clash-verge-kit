# CLI 是唯一正式产品入口

Clash Verge Kit 采用前台 Node.js CLI 作为唯一正式产品入口，并删除 React 页面、localhost 服务和浏览器启动链路。CLI 已覆盖当前高频的本机发现、目标与子订阅选择、生成、遮罩预览、剪贴板导出和安全脚本写入；继续维护 Web 会扩大依赖、测试和用户流程，而重新实现生成器会制造两套安全语义，因此 CLI 直接复用现有 TypeScript 核心。

## Considered Options

- **保留 Web + CLI 双入口**：放弃，因为两套入口要求长期维护不同能力、构建与测试。
- **CLI 重新实现生成和写入逻辑**：放弃，因为会让完整性、安全写入和脚本格式发生分叉。
- **等待 Web 功能完全等价后再切换**：放弃；当前高频流程已经足够，Web 独有的 AI、更新、复原和脚本导入暂列为范围外，不阻止正式收束。

## Consequences

- `npm run cli`、构建后的 `dist/cli/cli.mjs` 和运行同一产物的 `.cmd` 是唯一运行路径；CMD 只在产物缺失时构建一次，日常启动直接复用现有构建。
- CLI 默认只展示生成摘要和必要警告；生成后的操作全部平铺在同一个数字菜单中，不保留“更多操作”子菜单。每个数字菜单使用空行和文本分隔线建立层级，不以终端颜色承载含义；配置详情与遮罩脚本仍只在用户请求后显示。
- 当前目标主订阅只在统一列表中出现一次，并且必须来自 Clash Verge Rev 本机发现；CLI 不提供手工目标 URL 或自动导入目标订阅。自动发现失败时只允许指定配置位置，仍未找到则提示先在 Clash Verge Rev 导入。唯一检测到的 `select` 主代理组直接使用，多个检测结果只在同一个常用选择流程中显示，每页最多 10 个，并支持翻页和关键词筛选。未检测到主代理组时返回目标选择，不把 `MATCH`/`FINAL` 兜底目标推断为主代理组，也不提供运行时猜测或手工输入入口。首次语言菜单和目标主订阅菜单的 `0` 退出，目标选定后的数字 `0` 只返回紧邻的上一步。
- 子订阅名称直接作为默认子组名称；追加、改名、详情、遮罩脚本和重新配置与“检查方向并继续”处于同一层。同一配置最多支持 64 个子订阅，CLI 在达到上限时停止追加，生成器仍负责最终拒绝超限或重复来源的输入。写入与复制共用一次方向复核，成功后进入只能重新配置或退出的完成状态。
- CLI 复制和安全写入直接交付生成器的可读脚本，不再为了缩小文件二次压缩或把多个语句拼在同一行。
- Web 独有能力不会随入口切换自动迁移；未来恢复图形入口需要新的规格和架构决策。
- 写入后不通过 Clash Verge Rev External Controller 或其他客户端接口自动改变主代理组当前选中项，也不为模拟自动选择而调整子组顺序。
- 已被取代的 Web 规格、研究与实施记录不再保留在当前文件树，需要追溯时使用 Git 历史。
- npm 包已按公开发布配置，但尚未发布；首次发布完成后，普通用户入口才是 `npx clash-verge-kit`。
